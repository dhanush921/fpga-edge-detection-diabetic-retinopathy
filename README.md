## FPGA-Based Edge Detection for Diabetic Retinopathy Screening

Microchip PolarFire SoC Discovery Kit | FPGA-Based Image Processing

## Problem Statement

Diabetic Retinopathy can cause vision impairment if retinal abnormalities are not detected early. Traditional retinal image processing can be limited by processing speed and noise tolerance, especially for large-scale screening. 

## Proposed Solution

An FPGA-based edge detection system is proposed to process retinal fundus images efficiently. The system converts images to grayscale, applies Gaussian smoothing, performs edge detection and gradient computation, and generates a binary edge map for further analysis. 

## Technology

Microchip PolarFire SoC FPGA

RISC-V Processor

MIPI CSI-2 Image Input

DDR4 SDRAM

FPGA-based parallel image processing

Sobel / Prewitt / Scharr / Laplacian / Roberts edge detection

Gradient calculation & thresholding


## Applications

Diabetic Retinopathy screening

Retinal vessel and abnormality detection

Point-of-screening retinal image analysis

Low-latency edge-based medical image processing
